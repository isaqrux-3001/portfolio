How I work with AI

AI is part of how I design, test and ship.

02.1

The biggest change

Design decisions that start from the real source of truth

Claude Code is connected to the product’s local code repository and to Figma at the same time. When I make a design decision, I check it against the real source of truth: the code that ships and the designs in Figma.

From brief to concept

With Claude connected to Figma, a written brief becomes a first concept in minutes. I refine it from there by hand.

02.4

Real software for testing

I built a working Android version of Certify in two days, so testing happens on real software instead of a click-through prototype.
